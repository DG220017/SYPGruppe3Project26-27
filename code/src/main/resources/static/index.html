ℹ️ Hinweis zur Steuerberechnung

Die Steuerkennzahlen werden aus den in MoneyTracker erfassten Transaktionen berechnet. In dieser Demo-Version sind noch keine Umsatzsteuer- oder Vorsteuerbeträge hinterlegt.

Die angezeigten Werte sind daher keine vollständige steuerliche Berechnung und keine fertige Umsatzsteuererklärung.
